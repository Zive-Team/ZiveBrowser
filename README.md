 🌐 Zive browser (ザイヴ ブラウザ)

[![Electron](https://shields.io)](https://electronjs.org)
[![License](https://shields.io)](LICENSE)
[![Platform](https://shields.io)]()

**Zive browser** は、HTML/CSS/JavaScript（Electron）を活用して開発された、圧倒的な使いやすさと強固なプライバシー保護を両立した次世代のマルチタブ型Webブラウザです。

Google Chromeに近い直感的なUI（ユーザーインターフェース）を備え、現代の法律・セキュリティ要件に準拠したセキュアなブラウジング体験を提供します。

---

## ✨ 主な機能

### 1. 基本ナビゲーション & タブ管理
- **オムニボックス**: URL入力による直接移動、およびキーワード入力時の自動Google検索。
- **マルチタブ制御**: 動的なタブの追加（＋）、削除（×）機能。開いているサイトのタイトルとファビコン（アイコン）を自動取得して表示。
- **ナビゲーション制御**: 「戻る」「進む」「再読み込み」の直感的な操作。
- **ポップアップブロック**: 悪質な広告などによる意図しない別ウィンドウの強制立ち上げを防止。

### 2. 🔗 スマート共有機能
アドレスバー右側の共有ボタンから、閲覧中のページを素早くシェアできます。
- **リンクコピー**: URLをクリップボードにコピー（完了通知ポップアップ付き）。
- **QRコード生成**: 現在のURLをその場でQRコード化して画面に表示。
- **SNS連携**: X（旧Twitter）やLINEの投稿画面をセキュアな別ウィンドウでポップアップ表示。

### 3. 🔐 プライバシー ＆ セキュリティ（法的配慮）
- **ローカルデータ一括消去**: 個人情報保護法や電気通信事業法に基づき、設定画面から「閲覧履歴」「クッキー（Cookie）」「キャッシュ」をボタン一つで完全消去。
- **外部送信の制限**: ユーザーの閲覧データや個人情報を外部のサーバーへ送信・収集することは一切ありません。
- **SSL/TLS警告**: 非暗号化サイト（`http://`）へのアクセス時に、アドレスバーに赤字で「⚠️ 保護されていない通信」と警告を表示。
- **プロセス分離**: `contextIsolation` および `nodeIntegration` の最適化により、閲覧中のWebサイトからPC内のローカルファイルへの不正アクセスを徹底遮断。
- **OS連携フィルタリング**: 青少年インターネット環境整備法等に基づく有害サイトのブロック（閲覧制限）は、無駄なブラウザ負荷を避けるため、OS標準機能（Windowsファミリーセーフティ / Macスクリーンタイム等）に処理を委ねる仕様としています。

### 4. ⚙️ 詳細設定画面
- **2カラムレイアウト**: 左メニュー、右詳細の直感的な構成。
- **カスタマイズ**: カラーテーマ（ライト/ダーク）の選択、起動時に開くページの登録、ダウンロード先フォルダの変更。
